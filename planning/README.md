1. **Bukan Sekadar CV Berjalan:** Menghidupkan *storytelling* 5 Chapter perjalanan (Kampus $\rightarrow$ Kepemimpinan UKM FK $\rightarrow$ KADA AI $\rightarrow$ BBPVP Web $\rightarrow$ Karya Nyata).
2. **Kredibilitas Teknis Jujur & Tajam:** Membedakan proyek produksi/flagship (seperti *LENTERA RAG Chatbot* dan *Absensi PSA*) dengan proyek eksplorasi konsep.
3. **Desain Kelas Dunia (High Polish):** UI minimalis bergaya technical engineering (monochrome slate + warm/electric accent, monospace micro-copy, grid subtle, card border glow halus).
4. **Performa & Responsif:** Ringan, interaktif, cepat diakses mobile maupun desktop.
